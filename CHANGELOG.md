## [0.1.0] - 2026-10-05

### Added

- Independent Kotlin/JVM 17 Taiwanese sixteen-tile hand structure, exact copy-aware shanten, effective tiles, discard analysis and five-meld winning decompositions.
- Source-qualified Pocket and composed Southern scoring profiles, configurable values/exclusions, ordinary scoring and distinct flower victories.
- Java/Kotlin Maven consumers, checked public ABI, sources and Dokka API reference in a standard javadoc JAR, publication metadata checks and signed Central Portal publishing.

### Rules baseline

[The 0.1.0 RULES.md ledger](https://github.com/SkyEye-FAST/taiwan-mahjong/blob/0.1.0/RULES.md) freezes the current scoring definitions, exclusions, interpretations and supported structural forms. This release changes packaging and validation without expanding algorithms or changing rule semantics or public call shapes.
